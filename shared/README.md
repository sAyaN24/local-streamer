# streammark-shared

Config (`Settings`/`get_settings`), JSON logging setup, and LiveKit JWT/`VideoGrants`
minting (`mint_viewer_token`, `mint_broadcaster_token`, `mint_publisher_token`,
`mint_logger_bot_token`) shared by [`backend-webserver`](../backend-webserver)
and [`stream-publisher`](../stream-publisher). Not meant to be installed alone.

```bash
pip install -e .
```
